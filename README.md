# Naman Kumar

I build agents and the infrastructure around them: persistent context, tool integrations, permissions and verification. My work spans customer operations, software delivery and financial infrastructure. Python and TypeScript. YC S16.

Previously founded a YC-backed company, delivered wallet initiatives driving **$200M+ in transaction volume**, and scaled account abstraction to **2.1M agents and humans**.

## Selected projects

### [Agent Work Continuity](https://github.com/namankumar/agent-work-continuity)

A runnable example of keeping agent work consistent across sessions. Persistent state, replay-safe changes, stale-update rejection and verification receipts, using fictional inputs. Extracted from working coordination infrastructure; the demo’s limits are documented.

### [Onchain Portfolio Reconstruction](https://github.com/namankumar/onchain-portfolio-reconstruction)

Trace movements, decode EVM receipts and internal calls, and reconcile balances using exact integer accounting. A portable Python core with synthetic examples, offline tests and documentation of the wider investigation’s chain and protocol coverage. No keys, signing or transaction broadcasting.

### [Privacy Score](https://github.com/namankumar/privacy-score)

A TypeScript/Next.js wallet-analysis project combining deterministic scoring across six privacy categories with Claude-generated explanations and remediation guidance. Developed during work at Provable.
