# Naman Kumar

I build agents and the systems around them: company context, tool integrations, permissions, persistent state and verification. My work spans customer operations, software delivery and financial infrastructure. Python and TypeScript. YC S16.

Previously founded a YC-backed company, delivered wallet initiatives driving **$200M+ in transaction volume**, and scaled account abstraction to **2.1M agents and humans**.

## Selected projects

### [Company OS](https://github.com/namankumar/company-os-showcase)

A company-context workspace that turns plans, meeting notes and work records into source-linked briefs and proposed decisions. Includes a fictional workspace, host-run skills, worked outputs and a citation checker.

### [Agent Infrastructure](https://github.com/namankumar/agent-infrastructure)

Architecture of hosted MCP integration, OAuth and SQL-backed agent work. The runnable public subset demonstrates persistent state, replay-safe updates, stale-write rejection and review receipts. The full hosted implementation remains private.

### [Voice and SMS Operations](https://github.com/namankumar/voice-sms-operations)

An offline replay of customer-request capture, retry handling and staff handoff ownership. Synthetic scenarios show exact retries, conflicting updates and protection against resetting an already-owned callback. No live phone or SMS service is required.

### [Onchain Portfolio Reconstruction](https://github.com/namankumar/onchain-portfolio-reconstruction)

Trace movements, decode EVM receipts and internal calls, and reconcile balances using exact integer accounting. A portable Python core with synthetic examples, offline tests and documented capability coverage. No keys, signing or transaction broadcasting.
