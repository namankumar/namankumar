# Naman Kumar

I'm a founder and product builder. I work in Python and TypeScript, building tools for the work that falls between a conversation and a finished task. I founded Airo Health (YC S16) and have since worked across developer tools, wallets and AI products.

My recent projects cover a few problems I've spent time on: keeping track of work across agents, answering questions without leaking company information, and making sure a phone request reaches someone who can act on it.

## Start here

### [Agent Infrastructure](https://github.com/namankumar/agent-infrastructure)

A shared workspace for people and agents, with a browser UI, SQLite storage and an MCP interface. Tasks keep their source references, updates are versioned, and retried requests don't create duplicate writes. You can run it locally without connecting an account.

### [Voice and SMS Operations](https://github.com/namankumar/voice-sms-operations)

The operations code and staff dashboard behind a voice/SMS system. It tracks what a caller asked for, who owns the next step, and whether the underlying action actually happened. Start with the fictional-data dashboard preview. The public export includes offline checks, not a live phone service.

### [Company Knowledge System](https://github.com/namankumar/company-knowledge-system)

A backend for answering questions from company sources while respecting who can read each source. It checks access before retrieval and carries evidence references into the answer. The public repo includes the implementation and offline tests; it doesn't include the original frontend or a complete hosted setup.
